# Wake Up

一个 NeoForge 模组（Minecraft 1.21.11）。睡觉跳过夜晚时，有概率进入"梦境"——梦境中一切正常游玩，但梦境结束时整个服务器会**回滚**到睡醒那一刻。支持梦中梦（多层嵌套）。

## 玩法

1. 上床睡觉、跳过夜晚（多人需所有玩家都入睡）。
2. 睡醒时以 `dreamChance` 的概率进入梦境。
3. 梦境中正常游玩，但所有改动都是临时的（方块、物品、实体、时间等）。
4. 待到苏醒后回滚到睡醒那一刻。
5. 梦中再睡觉并跳过夜晚 → 进入更深一层（梦中梦），外层计时暂停；苏醒按后进先出逐层回滚。

细节：
- 死亡：单人死亡 = 立即醒梦；多人只有**所有在线玩家同时死亡**才醒梦。
- 梦中所有玩家退出 → 倒计时暂停，有人重连后继续。

## 配置

游戏内：`Esc` → 模组列表 → Wake Up → Config（或直接改 `config/wakeup-server.toml`）。

| 键 | 默认 | 说明 |
|----|------|------|
| dreamChance | 0.5 | 每次睡觉做梦的概率（0.0 ~ 1.0） |
| dreamMinSeconds | 300 | 梦境最短时长（秒） |
| dreamMaxSeconds | 1200 | 梦境最长时长（秒），每次在 [最短, 最长] 内随机 |
| wakeOnDeath | true | 全员同时死亡时是否醒梦 |

## 命令

需要OP权限。

| 命令 | 作用 |
|------|------|
| `/wakeup status` | 查看是否做梦、层数、剩余时间 |
| `/wakeup force` | 开关"下次睡觉必定做梦" |
| `/wakeup dream` | 立即进梦（可重复执行测试梦中梦） |
| `/wakeup wake` | 立即醒梦并回滚 |
