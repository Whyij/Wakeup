# Wakeup

一个 NeoForge 模组，适用于 **Minecraft 1.21.11**。能让玩家体验到做梦

## 玩法 / Gameplay

1. 玩家上床跳过夜晚。
2. 起床那一刻，以概率 `dreamChance` 触发做梦。
3. 梦境中一切照常游玩，但改动都是"临时的"。
4. 梦境时间结束 → 苏醒 → 服务器**回滚到快照**。
5. 长时间不睡觉后睡觉增加概率做梦且有概率能不睡觉直接进入梦境（详见失眠）
6. 开局给的图腾可以区分自己是否处于梦境（默认不给，在游戏规则处更改）（默认隔20分钟才能使用1次）

### 失眠 / Insomnia

- 玩家**长期不睡觉**会积累"熬夜数"；每熬一夜，每刻进梦概率上升。
- 命中后随机进入一场**失眠梦**（时长是睡觉梦的x倍，默认0.5）。
- 正常睡一觉后熬夜数**清零**。

## 配置 / Config

配置文件生成在 `config/wakeup-common.toml`，可在**主菜单**或游戏内 **Mods 列表**直接编辑。

| 选项名称                         | 默认                                                                                | 说明                                  |
|------------------------------|-----------------------------------------------------------------------------------|-------------------------------------|
| `做梦概率`                       | `0.2`                                                                             | 睡觉跳过夜晚后进入梦境的概率（0.0–1.0）             |
| `每熬一夜增加的睡觉做梦概率`              | `0.05`                                                                            | 每熬一夜增加的睡觉做梦的概率（0.0–1.0）             |
| `睡觉做梦最大概率`                   | `1.0`                                                                             | 睡觉做梦的最大概率（0.0–1.0）                  |
| `最短做梦时长（秒）`                  | `300`                                                                             | 梦境最短时长（秒）                           |
| `最长做梦时长`                     | `1200`                                                                            | 梦境最长时长（秒），每次在 [min,max] 内随机         |
| `失眠做梦开关`                     | `true`                                                                            | 失眠机制开关                              |
| `最小每刻触发失眠概率（%）`              | `0.0`                                                                             | 失眠最小每刻概率（%）                         |
| `最大每刻触发失眠概率（%）`              | `0.15`                                                                            | 失眠最大每刻概率（%）                         |
| `每熬一夜增加失眠概率（%）`              | `0.004`                                                                           | 每熬一夜增加的概率（百分点）                      |
| `失眠梦境时长倍率` | `0.5`                                                                             | 失眠梦时长倍率（相对睡觉梦随机时长范围）                |
| `全员同时死亡时醒梦`                | `true`                                                                            | 全员同时死亡时是否醒梦（单机=该玩家死亡）               |
| `即将苏醒阶段的提前秒数`         | `1.5`                                                                             | 剩余多少秒进入"即将苏醒"阶段（开始施苏醒前效果），设为 0 关闭   |
| `苏醒前效果列表`          | `minecraft:nausea:0:9:1;minecraft:slowness:0:5:1;minecraft:darkness:0.5:5:1`      | 即将苏醒时依次施加的效果                        |
| `苏醒后效果列表`           | `minecraft:blindness:0:3:1;minecraft:slowness:0:1.5:4;minecraft:slowness:1.5:2:1` | 苏醒后依次施加的效果                          |
| `苏醒后粒子列表`         | `minecraft:end_rod:0:40`                                                          | 苏醒后依次生成的粒子                          |
| `苏醒音效ID`                | `minecraft:block.portal.travel`                                                   | 苏醒音效 ID（空字符串关闭）                     |
| `音效播放时机`              | `before`                                                                          | 音效时机：`none`/`before`/`after`/`both` |
| `图腾使用冷却（秒）`                | `1200`                                                                            | 图腾的使用间隔时间                           |

- 效果格式：`效果ID:延迟秒:持续秒:等级`，多个用 `;` 分隔。
- 粒子格式：`粒子ID:延迟秒:数量`，多个用 `;` 分隔。

## 命令 / Commands

> 需要作弊权限。

| 命令 | 作用 |
|------|------|
| `/wakeup status` | 查看是否做梦、层数、剩余时间 |
| `/wakeup insomnia` | 查看失眠状态：熬夜数、当前每刻概率、概率配置 |
| `/wakeup force` | 开关"下次睡觉必定做梦"（再执行一次关闭） |
| `/wakeup dream` | 进入睡觉梦（随机时长） |
| `/wakeup dream sleep [秒]` | 进入睡觉梦（不写秒数为随机时长） |
| `/wakeup dream random [秒]` | 进入随机梦/失眠梦（时长 × 倍率） |
| `/wakeup wake` | 立即醒梦（弹栈 + 回滚） |
| `/wakeup time <秒>` | 设置最深层剩余时长 |
