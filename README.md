# Wake Up

一个 NeoForge 模组（Minecraft 1.21.11）。睡觉跳过夜晚时，有概率进入"梦境"——梦境中一切正常游玩，但梦境结束时整个服务器会**回滚**到睡醒那一刻。

## 玩法

1. 上床睡觉、跳过夜晚（多人需所有玩家都入睡）。
2. 睡觉后有概率（可配置）进入梦境。
3. 梦境中正常游玩，但所有改动都是临时的（方块、物品、实体、时间等）。
4. 待到苏醒后回滚到睡醒那一刻。

细节：
- 玩家几乎无法察觉自己进入梦境
- 梦中退出游戏（所有玩家离线）会暂停梦境计时，重连后继续计时（退出无法离开梦境）

## 配置

游戏内：`Esc` → 模组列表 → Wake Up → Config（或直接改 `config/wakeup-server.toml`）。

| 键 | 默认 | 说明 |
|----|------|------|
| dreamChance | 0.5 | 每次睡觉做梦的概率（0.0 ~ 1.0） |
| dreamMinSeconds | 300 | 梦境最短时长（秒） |
| dreamMaxSeconds | 1200 | 梦境最长时长（秒），每次在 [最短, 最长] 内随机 |
| wakeOnDeath | true | 全员同时死亡时是否醒梦 |

## 命令

需要OP权限。

| 命令 | 作用 |
|------|------|
| `/wakeup status` | 查看是否做梦、层数、剩余时间 |
| `/wakeup force` | 开关"下次睡觉必定做梦" |
| `/wakeup dream` | 立即进梦 |
| `/wakeup wake` | 立即醒梦 |
